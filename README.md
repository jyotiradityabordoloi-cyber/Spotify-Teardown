# Does Spotify Listen to You? A Product Teardown

A PM case study on how Spotify helps listeners find new music, and **Playlist Coach**, an MVP that lets you steer the radio you already started.

- **Problem:** Radio, shuffle and autoplay recycle songs you already know. Skipping doesn't change what plays next.
- **Insight:** The dashboard logs a healthy 30-minute session. The listener found zero new songs.
- **MVP:** Intent check-in, discovery dial, live coaching, feedback that sticks, and "why this song".
- **Proof:** A 4-week A/B test. North Star: new-track saves per user per week, +10%.
